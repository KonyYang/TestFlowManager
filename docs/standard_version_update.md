# 标准版本更新功能说明

## 功能概述

标准版本更新功能用于从外部标准文件中提取最新的标准版本号，并更新Matrix中的测试方法列。该功能通过匹配测试方法的核心标识（如364-xx）在外部标准文件中查找对应的完整标准编号，并提取其后的版本符号更新到Matrix中。

## 配置说明

### 标准文件路径配置

标准文件路径在 `src/app/config/paths.ini` 文件中配置：

```ini
[STANDARD_FILES]
standard_version_info_file = D:\Source\Foreign file directory_20240422.xls
```

## 使用方法

1. 在Matrix编辑器界面中点击"更新标准版本"按钮
2. 系统会自动从配置文件中读取标准文件路径
3. 解析Excel文件中的"认可标准"工作表
4. 匹配Matrix中"Test Method"列的测试方法与标准文件中的标准
5. 更新匹配到的测试方法，添加版本符号

## 技术实现细节

### 核心方法提取

使用正则表达式 `364-\d{2}` 提取测试方法的核心标识，例如：
- "EIA-364-01" -> "364-01"
- "364-10A" -> "364-10"

### 版本符号提取

在完整标准编号中查找核心方法标识后第一个字母作为版本符号：
- "EIA-364-01A" 中的 "A"
- "EIA-364-10B Test" 中的 "B"

### 更新规则

1. 空格会被替换为短横线
2. 只更新包含核心方法标识的测试方法
3. 不会覆盖已有的版本符号

## 注意事项

1. 确保外部标准文件路径正确且文件存在
2. 确保Excel文件包含"认可标准"工作表
3. 标准文件格式应符合预期（第2列是文件编号）
